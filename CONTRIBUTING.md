# Contributing

MEDORA is an early educational pilot. Useful feedback describes the learning problem, expected behaviour and what happened, using a short synthetic or permission-cleared educational example. Include browser/device details for interface issues. Never attach patient records, private notes, API keys or identifying health data.

For a code change, explain the learner-facing behaviour, keep it focused, run `pnpm check` and the relevant tests, and state whether live AI or only mocked responses were tested. Preserve source/context distinctions, evidence caveats, accessible text sizing and hidden active quiz answers. Medical explanations require appropriate human review; passing software tests does not establish clinical accuracy.

Discuss substantial contributions with Rifana before submitting. No contribution licensing agreement or broad reuse license is implied by this document. See LICENSE.md.
